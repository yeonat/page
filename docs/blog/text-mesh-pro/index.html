Text Mesh Pro

Text Mesh Pro es un asset gratuito para Unity, permite cambiar la apariencia y diseño del texto.

Texh Mesh Pro usa etiqutas similares a las que usa HTML o XML, su sintaxis es menos estricta. Algunas etiquetas necesitan etiquetas de cierre por el ámbito que operan, otras tienen atributos a los cuales se les asignan valores, estos valores pueden ser númericos como píxeles (20px), porcentajes (25%), unidades de fuente (1.25em).

Lista de Etiquetas

N° Etiqueta Resumen
1 align Alineación del texto
2 color Color
3 alpha Opacidad

Alineación del texto

Esta etiqueta anula la alineación general que tiene el texto, se coloca al inicio de un párrafo.

<align="right">Right
<align="center">Center
<align="left">Left

Color

Esta etiqueta cambia el color de la fuente, se puede especificar 8 tipos.

<color="black">black</color>
<color="blue">blue</color>
<color="green">green</color>
<color="orange">orange</color>
<color="purple">purple</color>
<color="red">red</color>
<color="white">white</color>
<color="yellow">yellow</color>

Además puede usar el código hexadecimal para especificar el color de la fuente, también puede definir el valor de alfa.

<color=#e35100>#e35100</color>
<color=#51a200>#51a200</color>
<color=#4192c3>#4192c3</color>
<color=#797979>#797979</color>
<color=#e35100cc>#e35100cc</color>
<color=#51a200aa>#51a200aa</color>
<color=#4192c388>#4192c388</color>
<color=#79797966>#79797966</color>

Opacidad

Esta etiqueta cambia solo la opacidad del texto, funciona con valores hexadecimales de 00 a FF, correspondiente de 0 a 255.

<alpha=#FF>FF
<alpha=#CC>CC
<alpha=#AA>AA
<alpha=#88>88
<alpha=#66>66
<alpha=#44>44
<alpha=#22>22
<alpha=#00>00
