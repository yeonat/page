Matemáticas 3D y Balística Predictiva en Unreal Engine C++: De Vectores a Cuaterniones

Matemáticas 3D esenciales: por qué los cuaterniones y el producto punto superan a los ángulos de Euler y a los raycasts.

Imagen por Emre Turkan.

Programar mecánicas de combate, seguimiento de proyectiles o cámaras en videojuegos requiere una base sólida de álgebra lineal y trigonometría. Confiar en soluciones aproximadas suele provocar rotaciones extrañas (Gimbal Lock), disparos que quedan siempre por detrás del objetivo o caídas imprevistas por punteros colgantes.

1: Producto Punto (A . B) y Conos de Detección

El producto punto relaciona algebraicamente dos vectores mediante el coseno del ángulo comprendido entre ellos:

$$\vec{A} \cdot \vec{B} = \vert{}\vec{A}\vert{} \vert{}\vec{B}\vert{} \cos(\theta)$$

Si ambos vectores están normalizados ( |A| = 1 y |B| = 1), la fórmula se simplifica a:

$$\cos(\theta) = \hat{A} \cdot \hat{B}$$

  • $\hat{A} \cdot \hat{B} = 1.0$: Alineación frontal perfecta ($0^\circ$).
  • $\hat{A} \cdot \hat{B} = 0.0$: Perpendiculares ($90^\circ$).
  • $\hat{A} \cdot \hat{B} = -1.0$: Totalmente opuestos ($180^\circ$).

Para saber si una torreta está alineada con su objetivo sin calcular costosos arcocosenos ( acos), calculamos el coseno de nuestra tolerancia angular una sola vez ( cos(Tolerancia)) y comprobamos:

$$\hat{Forward} \cdot \hat{Dirección} \ge \cos(\text{ÁnguloTolerancia})$$

2: Cuaterniones ( FQuat) frente a Ángulos de Euler

Los ángulos de Euler ( FRotator en Unreal: Roll, Pitch, Yaw) rotan en una secuencia de tres ejes ortogonales.

  • El Problema del Gimbal Lock: Cuando la inclinación vertical (Pitch) alcanza $\pm 90^\circ$, los ejes Roll y Yaw colapsan en el mismo plano.

  • La Solución ( FQuat): Un cuaternión $q = [x, y, z, w]$ describe una orientación 3D sin ambigüedad mediante un vector tridimensional de eje y una componente escalar de magnitud de giro sobre una hiperesfera unitaria cuatridimensional ($\mathbb{S}^3$).

  • SLERP (Spherical Linear Interpolation): Interpola suavemente a lo largo del círculo máximo de la esfera, manteniendo una velocidad angular constante y uniforme.

3: Balística Predictiva (Ecuación Cuadrática del Tiempo)

Disparar directamente a la posición actual de un objetivo en movimiento garantiza fallar el impacto. Para interceptarlo, debemos calcular la posición futura $\vec{P}_{\text{impact}}$ resolviendo el tiempo de vuelo $t$.

  1. La posición futura del objetivo tras un tiempo $t$ es:
$$\vec{P}_{\text{target}}(t) = \vec{P}_{\text{origin}} + \vec{V}_{\text{target}} \cdot t$$
  1. El proyectil parte de la torreta a rapidez constante $v_{\text{proj}}$, recorriendo una distancia:
$$d = v_{\text{proj}} \cdot t$$
  1. Igualando distancias con la posición relativa $\vec{R} = \vec{P}_{\text{target}} - \vec{P}_{\text{turret}}$:
$$\vert{}\vec{R} + \vec{V}_{\text{target}} \cdot t\vert{}^2 = (v_{\text{proj}} \cdot t)^2$$
  1. Al expandir la norma euclídea, se obtiene la forma cuadrática $A \cdot t^2 + B \cdot t + C = 0$:
$$A = \vert{}\vec{V}_{\text{target}}\vert{}^2 - v_{\text{proj}}^2$$$$B = 2 \cdot (\vec{R} \cdot \vec{V}_{\text{target}})$$$$C = \vert{}\vec{R}\vert{}^2$$

El discriminante $\Delta = B^2 - 4AC$ determina si el proyectil es capaz de alcanzarlo:

  • $\Delta < 0$: El objetivo se aleja más rápido de lo que el proyectil puede viajar; no existe solución matemática posible.

  • $\Delta \ge 0$: Calculamos las raíces y seleccionamos el menor tiempo positivo $t > 0$.

  • Caso especial ($A = 0$): Si la velocidad del objetivo iguala a la del proyectil, la ecuación se vuelve lineal ($t = -C / B$).

4: Interpolación Angular a Velocidad Constante

Para rotar un actor suavemente a una velocidad fija en grados por segundo sin saltos bruscos:

  1. Calculamos la distancia angular total en radianes entre la rotación actual y la deseada:
$$\theta = q_{\text{actual}}.\text{AngularDistance}(q_{\text{destino}})$$
  1. El avance angular máximo para el fotograma actual es:
$$\theta_{\text{max}} = \text{VelocidadEnRadianes} \times \Delta t$$

  1. Si $\theta \le \theta_{\text{max}}$, adoptamos la rotación final directamente.

  2. Si no, calculamos el factor de avance proporcional:

$$\alpha = \frac{\theta_{\text{max}}}{\theta}$$
  1. Aplicamos FQuat::Slerp(Actual, Destino, \alpha).

    bool CalculateInterceptPoint(const FVector& TargetPos,

    UPROPERTY(EditAnywhere, Category = "Turret Configuration")
    float ProjectileSpeed = 4000.0f;

    UPROPERTY(EditAnywhere, Category = "Turret Configuration")
    float RotationSpeedDegrees = 180.0f;

    float FireAngleToleranceDegrees = 3.5f;

    void SetTarget(AActor* NewTarget) { TargetActor = NewTarget; }

TurretPredictorComponent.cpp 
#include "TurretPredictorComponent.h"
#include "GameFramework/Actor.h"
#include "Engine/Engine.h"

UTurretPredictorComponent::UTurretPredictorComponent()
{
    PrimaryComponentTick.bCanEverTick = true;
}

bool UTurretPredictorComponent::CalculateInterceptPoint(const FVector& TargetPos,
                                            const FVector& TargetVel,
                                            float ProjSpeed,
                                            FVector& OutInterceptPoint) const
{
    AActor* Owner = GetOwner();
    if (!Owner || ProjSpeed <= 0.0f) return false;

    const FVector TurretPos = Owner->GetActorLocation();
    const FVector RelativePos = TargetPos - TurretPos;

    // Coeficientes: A*t^2 + B*t + C = 0
    const float A = FVector::DotProduct(TargetVel, TargetVel) - (ProjSpeed * ProjSpeed);
    const float B = 2.0f * FVector::DotProduct(RelativePos, TargetVel);
    const float C = FVector::DotProduct(RelativePos, RelativePos);

    float ValidTime = -1.0f;

    // Caso Especial: Si A es casi cero (velocidad del target == velocidad del proyectil)
    if (FMath::IsNearlyZero(A))
    {
        if (!FMath::IsNearlyZero(B))
        {
            const float LinearTime = -C / B;
            if (LinearTime > 0.0f)
            {
                ValidTime = LinearTime;
            }
        }
    }
    else
    {
        const float Discriminant = (B * B) - (4.0f * A * C);

        // Sin solución real: el proyectil nunca alcanzará al objetivo
        if (Discriminant < 0.0f)
        {
            OutInterceptPoint = TargetPos;
            return false;
        }

        const float SqrtDisc = FMath::Sqrt(Discriminant);
        const float T1 = (-B + SqrtDisc) / (2.0f * A);
        const float T2 = (-B - SqrtDisc) / (2.0f * A);

        // Seleccionamos el menor tiempo positivo en el futuro
        if (T1 > 0.0f && T2 > 0.0f)
        {
            ValidTime = FMath::Min(T1, T2);
        }
        else if (T1 > 0.0f)
        {
            ValidTime = T1;
        }
        else if (T2 > 0.0f)
        {
            ValidTime = T2;
        }
    }

    if (ValidTime <= 0.0f)
    {
        OutInterceptPoint = TargetPos;
        return false;
    }

    // Posición futura proyectada
    OutInterceptPoint = TargetPos + (TargetVel * ValidTime);
    return true;
}

void UTurretPredictorComponent::TickComponent(float DeltaTime,
                                ELevelTick TickType, 
                                FActorComponentTickFunction* ThisTickFunction)
{
    Super::TickComponent(DeltaTime, TickType, ThisTickFunction);

    // Validación segura mediante TWeakObjectPtr
    if (!TargetActor.IsValid()) return;

    AActor* Target = TargetActor.Get();
    AActor* Owner = GetOwner();
    if (!Owner) return;

    const FVector TurretLocation = Owner->GetActorLocation();
    const FVector TargetLocation = Target->GetActorLocation();
    const FVector TargetVelocity = Target->GetVelocity();

    FVector InterceptPoint;
    const bool bHasSolution = CalculateInterceptPoint(TargetLocation,
                                                TargetVelocity,
                                                ProjectileSpeed,
                                                InterceptPoint);

    // 1. Orientación deseada en cuaterniones
    const FVector DirectionToTarget = (InterceptPoint - TurretLocation).GetSafeNormal();
    if (DirectionToTarget.IsNearlyZero()) return;

    const FQuat TargetQuat = DirectionToTarget.ToOrientationQuat();
    const FQuat CurrentQuat = Owner->GetActorQuat();

    // 2. Interpolación angular constante y uniforme (SLERP corregido)
    const float AngularDistanceRad = CurrentQuat.AngularDistance(TargetQuat);
    const float MaxStepRad = FMath::DegreesToRadians(RotationSpeedDegrees) * DeltaTime;

    FQuat NewQuat;
    if (AngularDistanceRad <= MaxStepRad || FMath::IsNearlyZero(AngularDistanceRad))
    {
        NewQuat = TargetQuat;
    }
    else
    {
        // El factor Alpha real representa la fracción del ángulo que avanzamos este frame
        const float Alpha = FMath::Clamp(MaxStepRad / AngularDistanceRad, 0.0f, 1.0f);
        NewQuat = FQuat::Slerp(CurrentQuat, TargetQuat, Alpha);
    }

    Owner->SetActorRotation(NewQuat);

    // 3. Verificación de alineación mediante Producto Punto
    const FVector CurrentForward = Owner->GetActorForwardVector();
    const float CurrentAlignmentDot = FVector::DotProduct(CurrentForward, DirectionToTarget);
    const float RequiredDot = FMath::Cos(FMath::DegreesToRadians(FireAngleToleranceDegrees));

    if (CurrentAlignmentDot >= RequiredDot && bHasSolution)
    {
        if (GEngine)
        {
            GEngine->AddOnScreenDebugMessage(501, 0.05f, FColor::Green, 
                TEXT("[TORRETA] ¡Objetivo alineado! Solución de disparo fijada."));
        }
    }
}

6: Preguntas Frecuentes

  1. ¿Por qué no usar FRotator::GetNormalized() en vez de Cuaterniones para interpolar orientaciones?

Respuesta: Aunque FRotator::GetNormalized() previene valores fuera de $[-180^\circ, 180^\circ]$, una interpolación lineal entre ángulos de Euler ( RInterpTo) interpola cada eje por separado. Esto hace que la punta del cañón trace arcos curvos irregulares en lugar de una línea recta geodésica, alterando la velocidad angular a mitad de camino y sufriendo inestabilidad cerca de los polos de cabeceo ($\pm 90^\circ$). FQuat::Slerp garantiza la trayectoria más corta y una velocidad angular constante.

  1. ¿Qué ventaja de rendimiento ofrece el Producto Punto frente a un LineTrace para visión cónica?

Respuesta: Un LineTraceSingle requiere atravesar el árbol de jerarquía de volúmenes delimitadores de física (BVH de PhysX o Chaos) y comprobar colisiones triangulares en CPU. El producto punto son apenas tres multiplicaciones y dos sumas:

float Dot = A.X*B.X + A.Y*B.Y + A.Z*B.Z;

Permite descartar cientos de entidades fuera del campo de visión en nanosegundos antes de lanzar un único raycast físico para comprobar oclusión con paredes.
