Boy Adventure The Game

Plataformer Puzzle 2D con arte estilo pixel del Game Boy, desarrollado en 3 días.

Boy Adventure fue desarrollado para la GMTK Game Jam del año 2019, el tema Genre Without mechanics, use el género plataformas sin la mecánica de desplazamiento lateral, bloques te impiden moverte hacia alguna dirección y es necesario apretar el botón para poder desplazarse a un lado.

Ganas el juego cuando logras escapar de la mazmorra en la que te encuentras atrapado.
