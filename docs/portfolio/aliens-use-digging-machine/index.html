🚀 Aliens Use Digging Machine Full Gameplay

Las comunicaciones han fallado en las profundidades de la mina alienígena. Tu misión: calcular tus saltos con precisión, rescatar a los astronautas sobrevivientes, recolectar valiosos diamantes y escapar antes de que la colosal máquina excavadora te alcance. ¿Lograrás salir con vida?

🎮 Desarrollado en Unity.

Detalles de Desarrollo

Como creador en solitario, lideré el ciclo de desarrollo completo de este proyecto, encargándome desde el diseño de niveles, balanceo de gameplay y arte técnico, hasta la integración de sonido, UI/UX y la optimización final para WebGL y PC.

  • Sistemas y Mecánicas (C# / Unity): Programé la lógica central del juego, implementando físicas de movimiento avanzadas (salto cargado con gravedad dinámica y jump buffering), efectos visuales de paralaje vertical, un sistema de cámara dinámica y la IA del jefe final.

  • Arquitectura de Entrada: Diseñé un sistema de control robusto y desacoplado, compatible tanto con el Input Manager clásico como con el nuevo Unity Input System, garantizando soporte fluido para teclado y mando.

  • Optimización y Audio: Integré la gestión de audio ambiental, eventos narrativos y técnicas de optimización como object pooling, además de desarrollar una interfaz (HUD) totalmente responsiva.
