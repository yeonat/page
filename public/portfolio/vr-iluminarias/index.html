VR Iluminarias

Solución inmersiva en Realidad Virtual desarrollada para la industria minera.

La imagen de la portada pertenece al Instituto de Ingenieros de Minas del Perú

El video le pertenece a PlayTec EDU 4.0

Desarrollo de un simulador inmersivo en Realidad Virtual (Unity / Meta Quest) para la auditoría y validación de estándares de iluminación (lux) en minería subterránea. El sistema replica condiciones lumínicas reales a partir de datos técnicos de luxómetros para garantizar fidelidad operativa. Se aplicaron técnicas avanzadas de optimización para hardware móvil standalone, asegurando una tasa de refresco estable y una experiencia fluida sin sacrificar precisión fotométrica.
